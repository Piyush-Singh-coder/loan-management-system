# CreditSea - Frontend

This is the Next.js frontend for the CreditSea Loan Management System.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment variables in `.env.local`:
   ```env
   NEXT_PUBLIC_API_URL=http://localhost:5000/api
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## 🛠 Tech Stack
- **Next.js 14** (App Router)
- **Tailwind CSS**
- **Zustand** (State Management)
- **Axios** (API Client)
- **Lucide React** (Icons)

## 📂 Structure
- `/src/app`: Page routes and layouts.
- `/src/components`: UI components (Buttons, Inputs, Modals, etc.).
- `/src/store`: Global state management with Zustand.
- `/src/services`: API abstraction layers.
